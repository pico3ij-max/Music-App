# Music-App

A simple and interactive music player built with HTML, CSS, and JavaScript.

## Preview

![Music App Preview](./screenshot.png)

## Features

- ▶️ Play and pause songs
- ⏮️ Previous and next track
- 🔊 Volume control
- 🔇 Mute functionality
- 🔀 Shuffle songs
- 🔁 Repeat mode
- 📋 Add songs to a playlist
- 🎵 Display song title, artist, and cover
- ⏱️ Show current time and song duration
- 📊 Interactive music progress bar

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome
- Bootstrap Icons

## About

I built this music app as a JavaScript learning project to practice working with the DOM, events, audio elements, arrays, objects, and dynamic content.

The project helped me practice building interactive features and managing the state of a music player.

I hope you enjoy it! 🎵
